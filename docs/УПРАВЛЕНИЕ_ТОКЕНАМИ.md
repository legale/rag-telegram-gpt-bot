# Управление Токенами - Краткая Инструкция

## Что изменилось?

Добавлены новые возможности для управления контекстом и токенами:

### 🆕 Новые команды в Telegram

1. **`/tokens`** - Показывает текущее использование токенов
   ```
   📊 Использование токенов:
   
   Текущее: 3,245
   Максимум: 14,000
   Использовано: 23.18%
   
   ✅ Достаточно места для разговора.
   ```

2. **`/reset`** - Сбрасывает контекст разговора
   ```
   ✅ Контекст сброшен!
   ```

### ⚙️ Автоматический сброс

Бот теперь **автоматически сбрасывает контекст**, когда достигается лимит токенов.
Вы увидите предупреждение:
```
⚠️ Контекст был автоматически сброшен из-за достижения лимита токенов.
```

### 🔧 Настройка в .env

Добавьте в ваш `.env` файл:

```bash
# Максимум токенов перед автосбросом (по умолчанию: 14000)
MAX_CONTEXT_TOKENS=14000
```

**Для разных моделей:**

| Модель | Лимит контекста | Рекомендуемый MAX_CONTEXT_TOKENS |
|--------|----------------|----------------------------------|
| gpt-3.5-turbo | 16k | 14000 |
| gpt-4-turbo | 128k | 120000 |
| claude-3-sonnet | 200k | 190000 |

## Как использовать?

### Проверить использование токенов
Отправьте боту: `/tokens`

### Сбросить контекст вручную
Отправьте боту: `/reset`

### Увеличить лимит (если используете модель с большим контекстом)
1. Откройте `.env`
2. Измените `MAX_CONTEXT_TOKENS=14000` на нужное значение
3. Перезапустите бота

## Перезапуск бота

После изменения `.env` файла:

```bash
# Остановите бота (Ctrl+C в терминале)
# Запустите снова:
poetry run python src/bot/tgbot.py run -V 7
```

## Решение проблем

### Бот часто сбрасывается?
- Увеличьте `MAX_CONTEXT_TOKENS` в `.env`
- Или переключитесь на модель с большим контекстом (gpt-4-turbo)

### Хочу видеть больше контекста?
Используйте модель с большим окном контекста:
```bash
# В .env
OPENROUTER_MODEL=openai/gpt-4-turbo
MAX_CONTEXT_TOKENS=120000
```

### Как узнать, сколько токенов осталось?
Просто отправьте `/tokens` в любой момент разговора.
